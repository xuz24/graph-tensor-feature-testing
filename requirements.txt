# Recommended target environment for Great Lakes / GPU:
# 1. Create a Python 3.9 env.
# 2. Install PyTorch 2.1.0 with CUDA 12.1 via conda:
#    conda install pytorch==2.1.0 torchvision==0.16.0 torchaudio==2.1.0 pytorch-cuda=12.1 -c pytorch -c nvidia
# 3. Then install the packages below with pip.
#
# Notes:
# - These versions are scoped to the jumpstart_bundle graph-construction scripts, PLUS
#   tensograph_sage.py (Tucker decomposition + GraphSAGE baseline) built on top of them.
# - `torch` is intentionally not pinned here because the recommended install path on
#   Great Lakes is the conda GPU build above, not the default pip wheel.
# - `torch-geometric==2.4.0` is compiled against torch 2.1.0+cu121 -- if you change the
#   conda torch version above, get the matching PyG wheel index from
#   https://data.pyg.org/whl/ rather than just bumping this pin.
# - `torch-scatter` and `torch-sparse` are not required by tensograph_sage.py's SAGEConv
#   layers or by the original builder/split scripts, but many other downstream PyG models
#   will need them:
#   pip install torch-scatter torch-sparse -f https://data.pyg.org/whl/torch-2.1.0+cu121.html
